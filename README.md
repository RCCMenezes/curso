# Formação Data Science

Apresentação web autónoma para uma aula introdutória de Data Science, incluindo Machine Learning, Deep Learning, LLMs e um caso transversal de otimização de rotas com OR-Tools.

## Abrir localmente

Abra `index.html` num browser. Não é necessário instalar dependências.

## Controlos

- `←` / `→`, Page Up / Page Down ou espaço: navegar
- `F`: ecrã inteiro
- `N`: notas do formador
- `I`: índice
- gesto horizontal: navegar no telemóvel
- impressão do browser: exportar para PDF

## Publicar no Render

1. Coloque estes ficheiros num repositório GitHub.
2. No Render, escolha **New > Blueprint**.
3. Ligue o repositório e selecione o ficheiro `render.yaml`.
4. Confirme a criação do serviço estático.
5. Partilhe o endereço público gerado pelo Render com os alunos.

Como alternativa, crie um **Static Site** manualmente e configure:

- Build command: deixar vazio
- Publish directory: `.`

## Conteúdo

O guião extenso encontra-se em `Guiao_Formacao_Data_Science.md`. As notas específicas de cada slide estão integradas na apresentação e podem ser mostradas com a tecla `N`.
